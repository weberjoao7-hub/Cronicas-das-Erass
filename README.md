# Crônicas das Eras ⚔️

Protótipo web v0.4 do jogo de estratégia para celular e desktop.

## Como publicar
1. Abra [Settings → Pages](https://github.com/weberjoao7-hub/Cronicas-das-Erass/settings/pages).
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Em **Branch**, selecione **main** e **/(root)**. Clique em **Save**.
4. Espere o GitHub informar a publicação e abra https://weberjoao7-hub.github.io/Cronicas-das-Erass/.

O jogo usa um único index.html com mapa procedural, construção, conquista de regiões, tropas, eras e salvamento em armazenamento local do navegador.
